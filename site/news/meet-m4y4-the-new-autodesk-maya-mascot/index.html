Meet M4Y4, the New Autodesk Maya Mascot

AutodeskMayamascotcharacterArnold

I'm finally able to share this one! Autodesk brought me on to design, model and render the new mascot for the Maya Learning Channel, and M4Y4 is now officially out in the wild.

One of the key requirements was that the character had to be real-time friendly so it could live right inside the Maya viewport for training videos. That meant keeping the poly count in check and being smart about the textures rather than throwing SubD at everything. It was a fun constraint to design around.

It's a bit surreal to have a character of mine show up in the software I've been using since the late 90's. More views are up on the M4Y4 project page.
